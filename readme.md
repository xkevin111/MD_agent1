## Ability of the agent:

### Model construction:
1.	The initial model is generated by packmol package. The input file for packmol is generated locally. Then uploaded to hpc where packmol is installed.
2.	Generate the gromacs input file (.top and .mdp files) based on the simulation subject.
3.	Create the sub file for submission of simulation job.

### Run simulation:
1.	Check the available nodes in hpc and then submit the job by SLURM system.
2.	Check the output file of the simulation job time to time. If there are errors, go back to the Model construction section and modify the initial model or all of the input files to resolve the errors.

### Post-process:
1.	One simulation may contain several phases, such as energy minimization, equilibration, production. Determine difference phases based on the sub file, the gromacs input file and the simulation result files. 
2.	Analysis the physical property variation at difference phases during simulation (such as potential energy (PE), kinetic energy (KE), density (rho), pressure (P), temperature (T), etc.)
3.	Compute the mean of physical property after equilibrium. Find a way to determine the time when the system reaches equilibrium and then compute the mean.
4.	Several simulations with different parameters are conducted. Analysis the relation between different physical properties across different simulations, such as rho vs PE, rho vs T, PE vs P, etc.
5.	Make conclusions based on the analysis in step 4.
